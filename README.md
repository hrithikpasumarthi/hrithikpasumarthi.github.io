# Portfolio

A premium, highly-interactive portfolio website built with **React**, **Vite**, and **Framer Motion**. This project features a modern, theme-switchable UI with a specialized "VS Code" inspired projects section.

## 🚀 Key Features

- **VS Code Inspired UI**: A unique projects display mimicking the VS Code interface, complete with a file explorer and README view.
- **Dynamic Achievements**: Interactive accolades with smart, space-aware tooltips that provide detailed award timelines.
- **Theme Switcher**: Seamless transition between professional Dark and clean Light modes using CSS variables.
- **Fully Responsive**: Optimized for all devices, featuring a horizontal project switcher and adjusted spacing for mobile users.
- **Smooth Animations**: Powered by Framer Motion for a fluid and premium user experience.

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Build Tool**: Vite
- **Styling**: Modern CSS (Modules, Variables, Grid/Flexbox)
- **Animations**: Framer Motion
- **Icons**: React Icons (FontAwesome, VS Code, etc.)
- **Navigation**: React Scroll

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16.x or later)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the development server:
```bash
npm run dev
```

### Building for Production

To create an optimized production build:
```bash
npm run build
```
